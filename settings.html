System Settings

This section is available to administrators only. Use it to manage users, statuses and categories across modules.

Status Management

Category Management

Training Course Management

Define individual training courses. Each course has a title and is associated with a category. These training courses are used when scheduling training sessions and can be mapped to roles.

Role Management

Define employee roles used across the system. Roles can be assigned to employees when they are added.

Editor Roles

Select which roles are allowed to view and edit all records (in addition to Admin). These roles can access the settings page and manage all data.

QA Verification Roles

Select which roles are part of the Quality Assurance group. Users with these roles may verify actions in the system.

Training Categories by Role

Assign training categories to each role. Employees will be required to complete all categories assigned to their role.

Course Requirements by Role

Assign specific training courses to each role. Employees will be required to complete all courses assigned to their role.

Role & Module Permissions

Control which modules each role can access. Untick a module to hide it from users with that role. Administrators always have full access.

Notifications & Reminders

Configure email settings and default reminder timing. These values are used by the application to send assignment and due-date reminders.

Risk Scoring Thresholds

Define the threshold values used to determine risk ratings (Low, Medium, High). Adjusting these values will affect risk color coding and severity calculations across the system.

Interface & Localization

Toggle the layout direction for right-to-left languages. Enabling RTL will reorder text and menus to support Arabic and other RTL languages.

Retention & Reminder Settings

Configure how long records should be kept before automatic archival and override default reminder days for each module. Leaving a value blank disables automatic archival or uses the global reminder default.
